\section*{Software \& Research Tool Development}
\begin{itemize}
  \item \textbf{YourRA} (\href{https://yourra.org}{yourra.org}). Web platform for qualitative researchers that transcribes Bangla interview audio (IDIs, FGDs, KIIs) into a verbatim Bangla transcript, English translation, and a speaker-labeled Word report with demographic tables; built after seeing manual transcription and translation slow down research teams, cutting turnaround by roughly 4$\times$ and cost by at least 67\% versus manual work. Has processed 800+ minutes of audio for 30+ researchers to date
  \item \textbf{Stata Survey Toolkit} (\href{https://github.com/ashikpydev}{github.com/ashikpydev}). Suite of open-source .ado packages used across dRi survey projects; reduced repetitive cleaning workload by 25\%:
  \begin{itemize}[itemsep=1pt, topsep=2pt, parsep=0pt]
    \item \texttt{exportables\_3way} -- three-way cross-tabulations with direct Excel export; \texttt{exportables} -- dummy variables from multiple-response questions
    \item \texttt{multisplit} -- splits multiple-response variables into labeled dummies, handling repeat groups; \texttt{exprep} -- expands SurveyCTO repeat-group data into a flatter, analysis-ready format
    \item \texttt{recode\_oth} / \texttt{recode\_rep} / \texttt{recode\_nrep} -- recode open-ended ``other, specify'' text into existing categories
  \end{itemize}
\end{itemize}
